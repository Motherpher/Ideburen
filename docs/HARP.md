# Source governance — Pius Appendix O / HARP
Original Codex reviewed 2026-11-13. **RefA** full audit for public releases; **MinRA** for internal drafts.

- ITR1: locate attributed original source.
- ITR2: read complete relevant source; verify author, relevance, method and date.
- ITR4: Harvard reference with stable URL and access date.
- ITR5: manually cross-check measure, page, geography and denominators.
- ITR6: reject data whose verifiability/credibility/access cannot be established.

**No ITR3 is defined by this protocol; do not invent it.** Distinguish source-authenticity, extraction-accuracy, comparability and publication-rights. `metadata_only` is never equivalent to `primary_verified`.

The Uppsala 2022 values are taken from Marie Cederschiöld högskola (2025), *Civilsamhället i Uppsala län* (arbetsrapport nr 119), table 2, p.26 (data 2022); access 2026-11-13; urn:nbn:se:esh:diva-11246. Municipal codes derive from user-supplied mapping v3.9 (2025); **independent verification of the entire 290-code list against SCB 2026 remains required**.

Publication requires Director authorization and licensed/publishable data. Not-found, not-checked, zero and not-applicable are distinct.
