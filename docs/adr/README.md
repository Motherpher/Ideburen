# Architecture Decision Records

All changes affecting schema grain, canonical identifiers, geographic vintages, source-of-truth, license boundaries, public release or FF-Spatial integration require an ADR. Format: status, context, decision, alternatives, consequences, verification and approval. Never silently rewrite a decision; supersede with a new ADR. The Director retains authority for the architecture and publication decisions.

Statuses: Proposed → Accepted (after authorized human review) → Superseded / Rejected. An ADR may be written during implementation while still Proposed.
